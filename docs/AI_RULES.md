# AI Rules

These standing rules are given to every AI assistant working on this repo.
They are copied from the Build Plan and committed here so the repo shows how we work.

```
I am learning. Do not write large features unprompted.
- Propose a plan and wait for my approval.
- Change one file or concern at a time.
- Explain new concepts in plain language before the code.
- When I ask for a fix, show me the cause first.
- Never commit secrets; use environment variables.
```
